# 사마의전 구현 화면

[게임 실행](https://gnsyoo.github.io/threekingdom-jojo/) · [전체 시나리오·화면·검수](SIMA_CAMPAIGN.md)

현재 게임은 228년 상용 급습전, 234년 오장원 대치전, 238년 요동 포위전이다. 삼국연의 제94회·103~104회·106회의 사마의 관련 사건을 군의와 후일담에 반영한다. 마지막 요동 후일담에만 사마의의 짧은 독백 두 문장을 덧붙인다.

캐릭터는 몸·무기를 포함해 칸 안에 배치한다. 이름표는 12px 브라우저 글자로 표시하며 모바일은 최대 2배 해상도로 렌더링한다. 세로에서는 정보창을 지도 아래에, 가로에서는 오른쪽에 둔다.

UI 배치와 40개 화면 상태의 반복 검사 방법은 [UI 검수 기록](UI-REVIEW.md)에 있다. 조조편 시절의 과거 화면·검토 문서는 [이전 캠페인 검토](CAMPAIGN.md)에서 구분해 볼 수 있다.
