# 세로 화면 대응과 초반 3전투

[세로 화면과 가독성 개선 기록](PORTRAIT.md). 아래는 영천 전투를 실제 웹 게임에서 촬영한 화면이다. 새로 추가한 사수관·호로관은 [캠페인 검토 자료](CAMPAIGN.md)에 정리했다. [공개 게임 실행](https://gnsyoo.github.io/threekingdom-jojo/).

최근 개선: [UI·그래픽과 40개 화면 검수](UI-REVIEW.md). 초상·장비 비율, 큰 금액, 선택 화면, 선명한 이름표와 통일된 부대 크기를 보완했다.

## 군의와 대화

![실제 군의 대화 화면](images/story.png)

군의실 도트 배경과 양쪽 인물 초상을 유지하며, 대화창은 목재·금색·짙은 녹색과 이어지는 패널로 바꿨다. 세로에서는 선택지와 대화창을 차례로 쌓고 기록·자동 버튼을 아래에 둔다. 자동 재생은 선택지에서 멈추며, 출진 방침을 고르고 확인해야 준비 화면으로 넘어간다.

![모바일 군의 대화 화면](images/mobile-story.png)

## 출진 준비

![실제 출진 준비 화면](images/preparation.png)

[승인된 출진 준비 콘셉트](../design/images/preparation.png)의 3단 구성을 구현했다. 왼쪽은 출진 무장 목록, 중앙은 선택 장수의 큰 초상·레벨·경험치 초기값·HP/MP·장비 카드, 오른쪽은 출진 위치 지도와 보급품이다. 하단에는 장비·배치·상점·출진 메뉴를 배치했다.

현재 전투의 실제 출진 명단인 조조·유비·관우·장비와 시작 능력치를 표시한다. 장비는 기본 장비 정보를 확인할 수 있다. 배치는 조조의 시작 지역 9칸 중 한 곳을 선택하고 확정한다. 상점은 출진 지원금 200냥, 회복약 구매 100냥·되팔기 50냥·지참 한도 3개를 적용한다. 구매와 배치는 메뉴를 오가도 유지하고 출진할 때 저장한다.

![모바일 출진 준비 화면](images/mobile-preparation.png)

모바일 세로에서는 선택 장수·장비 → 무장 목록 → 출진 지도·보급 순서로 스크롤한다. 지도 비율을 유지하고 장비·배치·상점·출진은 하단에 고정한다. 메뉴 버튼은 최소 44px 크기다.

## 전투

![실제 데스크톱 전투 화면](images/desktop-battle.png)

상단 전투명·턴 표시, 오른쪽 장수 초상·HP/MP·종이 지형 정보, 하단 이동·공격·책략·도구·대기와 별도의 턴 종료 버튼을 콘셉트 구조로 배치했다. 지형 정보는 선택 장수의 실제 위치에 따라 바뀐다.

![실제 모바일 전투 화면](images/mobile-battle.png)

세로에서 장수 정보는 지도 아래에, 명령은 두 줄로 표시한다. 장수의 검은 그림자를 제거하고 얇은 진영 표시·깃발·이름표로 부대를 구별한다. 배경 밝기는 소폭만 조정한다. 지도는 드래그·휠·두 손가락으로 이동·확대할 수 있다. 전체 보기로 모든 부대를 확인할 수 있다.

## 부대 동작

10종 부대의 걷기 4포즈·공격 4포즈, 총 80개 새 프레임을 사용한다. 부대는 이동 경로의 각 칸을 따라 걸으며, 이동 완료 후 공격 자세와 짧은 전진 동작을 재생한다. 타격 자세에서 피격·회피·피해 표시를 내보내고, 반격은 선행 공격이 끝난 뒤 재생한다. 궁병은 화살을 발사하고 체력이 0인 부대는 사라진다.

AI의 다음 행동과 승패 화면은 실제 동작 완료를 기다린다. 빠른 속도 설정도 모든 공격 자세를 순서대로 재생한다. 현재 좌우 방향은 반전으로 제공하며 독립된 4방향 동작은 후속 제작 범위다.

## 검증

이번 UI 변경에서 코어 테스트 30개와 관련 브라우저 테스트 16개가 통과했다. 폰트 보완 뒤 UI·그래픽 검사 7개도 다시 통과했다. 화면 검수 40개 상태와 별도 스크린샷 검수 20건은 [검수 기록](UI-REVIEW.md)에 정리했다. 기존 전투 완주 검증은 상태를 강제로 바꾸지 않고 실제 버튼과 합법적인 이동·공격·회복·턴 종료로 진행한다.

- 전술 코어 30개: 이동·행동·AI·승패·저장·완주, 시작 위치 제한, 보급 예산·한도, 준비한 상태의 저장과 이동 되돌리기, 두 관문 전투·우군 회복·지원·진격 이벤트·이전 저장 호환.
- 이번 브라우저 16개: 준비 메뉴·구매·배치 상태 유지, 대화 자동·기록, 걷기 프레임과 공격·피격, 터치 이동·드래그, 세로·가로·태블릿·데스크톱 UI, 큰 금액·초상 비율·장비 정렬·선명한 이름표·동일한 부대 높이, 새 지휘관 초상과 회전.
- 세로 추가 검증 5개: 320×568·390×844·412×915의 글자 넘침·지도 비율·명령 크기·이벤트 복귀, 768×1024 준비 배치, 화면 회전 후 터치 이동·드래그·되돌리기.
- TypeScript 검사와 Pages 경로의 프로덕션 빌드.
- Pages 경로의 프로덕션 빌드에서 세 전투를 각각 데스크톱·모바일 터치로 출진하고 이벤트 발생 후 저장 복귀를 확인했다. 영천의 2턴 화공, 사수관의 3턴 관우 지원, 호로관의 3턴 여포 진격을 검사했다. 영천은 각 환경에서 리소스 23개, 두 관문 전투는 각각 26개가 정상 로드됐다. 실행 오류·실패한 요청은 없었으며 개발용 조회 기능도 제외됐다.

스크린샷은 데스크톱 1672×941, 모바일 390×844 뷰포트다. 모바일은 화면 밀도 2로 촬영했다. 실제 휴대폰 성능 측정 결과는 아니다.
