# 사마의전 아트·UI 명세

## 인물과 전장

짙은 남색·먹색·절제된 금속 장식을 사마의의 시각적 중심으로 쓴다. 사마의는 긴 얼굴, 사려 깊은 눈, 검은 관, 희끗한 수염과 어두운 부채로 구별한다. 사마사는 젊은 남색 장수, 우금은 투구를 쓴 노장, 곽회는 청록색 활 장수, 호준은 강철 투구와 남색 망토다. 맹달·공손연은 붉은 장수 계열, 제갈량은 흰 도포·검은 관·밝은 부채로 구별한다.

초상 8명은 `sima-portraits.png`의 4×2 아틀라스에서 실제 비율대로 자른다. 작은 얼굴 칸과 큰 정보 칸에서도 가로·세로를 다르게 늘리지 않는다. 군의에서는 좌우·하단 마스크로 초상 배경이 군의실과 자연스럽게 이어지게 한다. 발화자를 강조하고 준비·전투에서는 고정된 초상 프레임을 사용한다.

전장은 상용 산길·마을·동쪽 강과 다리, 오장원 평원·서쪽 숲과 위군 진영, 요동의 젖은 들판·양평성 관문으로 구별한다. 인물·문자·버튼을 배경에 굽지 않는다. 전장 그림은 원본을 보존하고 지도 칸 수에 맞춰 렌더링한다.

## 칸 안의 전투 캐릭터

- 전장 한 칸은 64×64 월드 픽셀이다.
- 각 캐릭터의 모든 걷기·공격 프레임에서 최대 너비·높이를 구해 **둘 모두 44픽셀 이내**로 균일하게 맞춘다. 무기까지 포함한다.
- 중심은 칸 가운데, 발은 칸 바닥에서 14픽셀 위다. 프레임의 가로 원점은 0.5, 세로 원점은 1이다.
- 깃발은 몸 왼쪽의 짧은 표식, 체력바는 발 아래의 48×8픽셀 칸이다. 진한 발밑 그림자는 쓰지 않는다.
- 공격 전진은 가로 4·세로 3픽셀로 제한하고 복귀한다. 걷기는 칸 사이를 연속 이동한다.
- 이름은 별도의 브라우저 레이어에서 12px로 표시한다. 지도 축소 시 일반 부대 이름을 줄이고 선택 장수·지휘관을 우선한다.
- 캐릭터와 배경은 부드럽게 필터링하고 캔버스 화면 밀도는 최대 2배다. 스케일과 터치 좌표에 같은 밀도를 적용한다.

## 준비 화면

데스크톱은 승인된 구조를 유지한다: 왼쪽 명단, 중앙 선택 장수·레벨·HP/MP·장비, 오른쪽 지도·보급. 모바일 세로는 장수 정보 → 장비 → 명단 → 지도·보급으로 스크롤한다. 하단 장비·배치·상점·출진을 고정하고 메뉴는 최소 44px다.

장비 아이콘은 고정 크기 칸의 중앙에 놓고 설명을 별도 칸에 둔다. 부채·활·창·검의 모양을 각각 사용한다. 금화 영역은 동전·보유 금화·숫자·상점 버튼으로 나누고, 100만 이상은 한국어 단위로 줄인다. 전체 금액은 접근성 이름·툴팁과 실제 거래 계산에 남긴다.

## 군의와 결과

군의는 발화자·본문·안내·계속 버튼을 같은 패널에 둔다. 대화는 여섯 장면이며 자동 재생은 마지막 전략 선택에서 멈춘다. 전략 카드에는 제목·설명·실제 효과·선택 체크를 둔다. 짧은 세로 화면에서는 확인 버튼을 하단에 고정한다. 선택 뒤에도 포커스와 스크롤 위치를 유지한다.

시작·대화·준비·모달 본문·장수 정보는 가로 넘침을 숨기고 터치는 세로 스크롤과 확대를 허용한다. 화면 밖으로 배치한 초상이 가로 스크롤 영역을 만들지 않게 한다. 전장 캔버스의 드래그·확대 입력은 별도로 유지한다.

전투 목표와 진행은 제압전과 방어전을 구별한다. 오장원에는 생존과 8턴 진행을 표시하고 제갈량을 퇴각 목표로 표시하지 않는다. 결과는 기본 승리·보조 목표·지표·원정 기록·동료 대화·다음 원정 순서다. 긴 결과 본문은 스크롤하고 진행 버튼을 고정한다.

## 검수 기준

320×568, 390×844, 844×390, 768×1024, 1440×900에서 버튼 문구·가로 넘침·초상 비율·금화·아이콘·이름표·캐릭터 경계를 검사한다. 터치 이동·확대·드래그·회전 뒤 좌표, 전투 이벤트·승패·저장 복귀도 확인한다. 검수 사진은 [실제 사마의전 기록](../prototype/SIMA_CAMPAIGN.md)에 있다.

독립된 4방향 프레임, 장비 강화·교체·성장, 네이티브 패키징과 실제 기기 성능 측정은 별도 제작 범위다.
