# 게임·시나리오 상세 기획 v0.1

가칭: **위의 군략**. 이름은 검토용이다.

## 1. 게임의 방향

원작 조조전에서 익숙한 전술의 순서와 역사극의 감각을 재현하는 싱글 플레이 SRPG다. 조조의 군대를 모으고, 장수별 병과·장비·지형을 활용해 전투를 이기고, 이야기 속 선택으로 동료와 결말이 바뀐다.

전장은 원작의 도트 감각을 살리되 갑옷·말·수목·기와·수면을 더 정교하게 표현한다. 인물 대화와 장수 상세에서는 새로 그린 정교한 일러스트를 사용한다. 대사·맵·수치·그래픽은 새 게임의 데이터로 제작한다.

| 항목 | 제안 |
|---|---|
| 플레이 | 가로 화면, 1인용, 턴제 사각 격자 전술 |
| 플랫폼 | 데스크톱·모바일 웹 → Android → iOS |
| 1회 전투 | 초반 8~15분, 후반 15~25분 목표; 실플레이로 조정 |
| 중단·복귀 | 각 확정 행동 뒤 자동 저장, 다음 실행에서 진행 중 전투 복구 |
| 주인공 | 조조, 함께 성장하는 장수와 책사 |
| 무대 | 후한 말~삼국 시대; 연의의 사건과 역사적 인물을 바탕으로 새 극본 작성 |
| 반복 플레이 | 선택·생존·장비·보조 목표로 달라지는 전개 |
| 최초 범위 | 전투 1개로 검증 → 초반 5전투 완성 |

원작의 “사실 모드”도 실제 역사 그대로는 아니다. 이 기획의 통일·연합 노선도 게임을 위한 가상 결말이며 역사 재현으로 표기하지 않는다.

## 2. 기본 플레이 흐름

**이어서 하기 → 사건·대화 → 군의 → 출진·장비·배치 → 전투 → 전리품·성장 → 사건 기록 → 다음 군의**.

- 사건: 현재 상황과 인물의 목적을 전달한다. 긴 설명은 사건 기록에서 다시 읽는다.
- 군의: 승리·패배 조건, 지형, 적의 특성을 보여준다. 중요한 위험을 예고한다.
- 출진: 필수 장수와 선택 장수를 고르고 장비·회복품·배치를 조정한다.
- 전투: 목표를 수행한다. 전멸전 외에 구원·탈출·방어·보급로 확보가 반복된다.
- 결과: 기본 보상, 보조 목표 보상, 성장, 다음 장의 변화를 보여준다.
- 야영지: 장수와 대화, 상점, 장비, 기록, 다음 출진. 반복 일과를 강요하지 않는다.

## 3. 전투 규칙 — 새 게임의 초기 제안값

### 3.1 격자와 라운드

- 지도는 평면 사각 격자다. 지형과 장식은 별도 레이어로 제작한다.
- 1라운드는 아군 → 우군 NPC → 적군이다. 턴 제한은 이 라운드 수를 센다.
- 장수는 해당 진영 차례에 이동 1회와 행동 1회를 할 수 있다.
- 기본 이동은 상하좌우다. 대각선 공격 여부는 병과·무기 범위가 결정한다.
- 행동 후 이동은 기본적으로 불가하다. 기병의 재이동은 후반 해금 후보다.
- 대기는 현재 위치에서 행동을 끝낸다. 이동 후 대기할 수도 있다.
- 같은 칸에 두 부대가 정지할 수 없다. 아군 칸은 통과할 수 있고 적군 칸은 막힌다.
- 아군 전원이 행동해도 자동으로 턴을 넘기지 않는다. 플레이어가 전장을 확인할 시간을 준다.

### 3.2 조작 상태와 되돌리기

`부대 선택 → 이동 후보 → 경로 미리보기 → 이동 → 행동 후보 → 대상·피해 미리보기 → 확정 → 행동 완료`.

이동은 공격·책략·아이템을 확정하기 전까지 되돌릴 수 있다. 단, 복병 공개·보물 획득·대화·지도 변경이 발생하면 해당 이동을 확정하고 되돌리기를 잠근다. 잠기는 이유를 UI에 표시한다. 공격 결과를 본 뒤 결과를 바꾸는 되돌리기는 제공하지 않는다.

### 3.3 초기 병과

초반 5전투까지 구현할 병과는 8종이다. 첫 전투에서는 군주와 기본 적병만 직접 경험하고, 차례로 새 역할을 해금한다.

| 병과 | 대표 장수 | 역할 | 초기 이동력 | 기본 공격 | 약점 |
|---|---|---|---:|---|---|
| 군주 | 조조 | 균형·아군 강화·목표 수행 | 5 | 인접 4방향 | 전문 공격수보다 순간 화력 낮음 |
| 기병 | 하후돈·조인 | 평지 돌파·보병 압박 | 6 | 인접 4방향 | 숲의 이동 비용, 궁병 |
| 보병 | 악진·조홍 | 길목·호위·궁병 제압 | 4 | 인접 4방향 | 기병의 돌파 |
| 궁병 | 일반 궁병 | 원거리·기병 견제 | 4 | 맨해튼 거리 2~3 | 인접 공격 불가, 보병 |
| 궁기병 | 하후연 | 빠른 원거리 지원 | 6 | 맨해튼 거리 2 | 숲·넓은 사거리 부족 |
| 책사 | 순욱 | 지형별 공격 책략 | 4 | 약한 인접 공격 | 물리 공격과 전열 노출 |
| 지원 | 순유 | 회복·해제·강화 | 4 | 약한 인접 공격 | 단독 전투 |
| 무도가 | 전위 | 가까운 적 압박·높은 회피 | 5 | 인접 8방향 | 원거리 집중 공격 |

궁병→기병→보병→궁병의 유리한 물리 공격에 1.20배를 초기값으로 적용한다. 궁기병은 공격 때 궁병, 피격 때 기병의 상성을 사용한다. 그 외 병과는 이 삼각 상성의 중립이다. 반격에도 같은 상성이 적용된다. 방패·장비 효과는 별도 계수다.

초반에는 군주·기병·보병·궁기병을 경험하고, 청주에서 책사·지원·무도가가 합류한다. 일반 궁병은 적과 연습 전투에서 등장한다. 후반에는 산적·기마책사·포차·수군을 순차적으로 추가한다.

### 3.4 지형

| 지형 | 보병 이동 비용 | 기병·궁기병 이동 비용 | 피해 감소 | 특징 |
|---|---:|---:|---:|---|
| 평지·길 | 1 | 1 | 0% | 기동에 유리 |
| 숲 | 2 | 3 | 15% | 길목 방어, 화계 조건 |
| 언덕 | 2 | 3 | 10% | 낙석 조건 |
| 얕은 물 | 2 | 3 | 0% | 수계 조건 |
| 다리 | 1 | 1 | 0% | 좁은 통로 |
| 마을·진영 | 1 | 1 | 10% | 진영 차례 시작 시 HP 10% 회복 |
| 성 내부 | 1 | 2 | 10% | 성문과 통로 전술 |
| 깊은 물·성벽 | 통행 불가 | 통행 불가 | — | 수군·문 파괴는 후반 기능 |

군주·궁병·책사·지원·무도가는 초기에는 보병 이동 비용을 사용한다. 특수 적병의 산지 적성은 해당 병과를 추가할 때 정의한다. 지형 패널에 이동 비용과 피해 감소를 직접 표시한다. 이미지에 있는 “평지 이동 +1”은 콘셉트 표현이며 실제 UI는 “이동 비용 1”로 표기한다.

### 3.5 능력치와 판정

- 성장 기반: 무력·지력·통솔·민첩·행운.
- 전투 표시: HP·MP·공격·정신·방어·회피·이동력. 전투 화면에는 HP·MP와 필요한 예측 정보부터 보여준다.
- 초기 물리 피해 제안: `max(1, 공격 − 방어 × 0.55) × 상성 × 지형 × 장비 효과`를 반올림한다.
- 초기 명중률 제안: `90 + (공격자 민첩 − 대상 민첩) × 0.4 + 보정`, 20~100%로 제한한다.
- 원거리·책략 반격은 기본적으로 없다. 근접 피격자는 생존하고 공격 범위가 닿을 때만 1회 반격한다.
- 회심·연속 공격은 5전투 검증 후 추가한다. 최초 전투의 튜토리얼에는 숨은 확률 변수를 늘리지 않는다.
- 피해 미리보기는 일반 피해, 명중, 반격 피해, 처치 가능 여부를 구분한다.
- 난수 상태를 저장한다. 단순한 재실행만으로 동일한 공격의 결과를 바꾸지 않는다.

이 공식은 원작의 역공학 결과가 아니다. 전투 1개를 플레이하면서 생존 턴과 선택의 의미를 검증하고 조정할 초기안이다.

|---|---|---|---:|
| 격려 | 아군 1명, 거리 2 | 공격 +10%, 2라운드 | 6 |
| 화계 | 평지·숲의 적 1명, 거리 3 | 정신 기반 피해; 비에는 불가 | 8 |
| 낙석 | 언덕의 적 1명, 거리 3 | 정신 기반 피해 | 8 |

| 소보급 | 아군 1명, 거리 3 | HP 회복 | 6 |

## 4. 성장·장비·실패

- 무기·방어구·보조 장비의 3슬롯이다. 장비 효과는 능력치와 전술적 특성을 구분해서 표시한다.
- 공격·지원·목표 달성으로 장수 경험치를 얻고, 사용·피격으로 장비 숙련도가 오른다.
- 우군 NPC가 적을 쓰러뜨려도 시나리오 기본 보상은 받는다. 플레이어 장수의 성장 독점을 위한 NPC 길막을 강요하지 않는다.
- 동료 구출과 보물은 보조 목표다. 획득 조건을 기록하며 비밀 보물은 범주만 암시할 수 있다.
- 일반 전투의 HP 0은 퇴각이다. 영구적인 장수 손실은 명확히 예고된 이야기 이벤트에서만 발생한다.
- 패배하면 출진 준비로 돌아가거나 저장 상태를 불러올 수 있다. 소모품과 성장의 반영은 승리 시 정산한다.
- 승급 시점은 원작을 참고해 Lv.15·30을 기본 후보로 삼는다. 첫 5전투에서는 Lv.3~8 구간을 검증한다.
- 적 레벨은 최초 전투 입장 때 고정하고 저장한다. 장비·레벨을 낮췄다 다시 입는 방식으로 난도를 조작하지 않게 한다.
- 난도: 이야기/표준/전술. 초기 제작 검증은 표준만 먼저 구현한다.

## 5. 전체 시나리오 구조

**공통 30전투 + 통일 노선 6전투 + 연합 노선 6전투 = 제작 대상 42전투**다. 한 회차에는 공통 30개와 선택 노선 6개, 총 36개를 플레이한다. 이는 신규 게임의 제작 범위이며 원작 전투 수를 뜻하지 않는다.

군의에서 조조의 결정을 쌓는다. 초기 선택은 사람·보급·정보에 영향을 주고, 30전투 뒤에는 누적 기록을 요약한 다음 플레이어가 최종 노선을 명시적으로 선택한다. 한 번의 실수로 모르는 사이 결말이 고정되지 않게 한다.

## 6. 첫 5전투 상세 설계

아래의 라운드·좌표·부대 수·보상은 제작 초안이다. 지도 크기는 전체 지도이며 모바일에 한 번에 전부 보이지 않는다. 좌표는 왼쪽 위가 `(0,0)`, 오른쪽이 +x, 아래가 +y다.

### S01 — 영천의 불길

**목적:** 이동→공격→대기→목표 수행을 1전투 안에서 익힌다.

- 지도: 18×12칸. 남서쪽 관군, 북동쪽 황건 진영, 중앙 길, 동쪽 하천.
- 플레이어: 조조 Lv.3 1명. 유비·관우·장비는 우군 NPC다. 원작처럼 주인공 한 명으로 시작해 조작 부담을 낮춘다.
- 적: 장보·장량 및 일반 황건 부대 6개, 총 8부대.
- 승리: 장보와 장량 모두 퇴각. 패배: 조조 퇴각 또는 12라운드 종료 시 목표 미달.
- 주요 위치: 조조 `(3,9)`, 장보 `(13,3)`, 장량 `(14,5)`, 회복 마을 `(6,7)`.
- 우군: 적의 약화를 돕되 플레이어의 접근 전에 보스를 혼자 제거하지 않는다. 보스 처치는 플레이어에게만 강제하지 않고 기본 성장 보상을 보장한다.

| 시점 | 이벤트 | 게임 상태 변화 |
|---|---|---|
| 전투 전 | 조조와 군관의 짧은 대화 | 목적과 조작 안내 3문장 |
| 아군 1라운드 시작 | 조조 선택·이동 안내 | 가능 칸 표시; 건너뛸 수 있음 |
| 첫 이동 후 | 첫 공격 안내 | 대상·예상 피해·반격 표시 |
| 아군 2라운드 시작 | 먼 진영에 화재; 우군 진격 | 황건 일반병 일부 1라운드 혼란; 보스 정상 |
| 조조 HP 40% 이하 최초 | 회복품 안내 | 보유 회복품 강조; 자동 사용하지 않음 |
| 첫 보스 퇴각 | 남은 목표 표시 | 목표 패널 `1 / 2` |
| 두 보스 퇴각 | 전투 종료 | 결과·첫 장비 숙련도 설명 |

보조 목표: 조조가 퇴각하지 않고 회복 마을을 이용하거나 회복품을 적절히 사용한다. 보상은 회복품 추가와 기록 배지다. 튜토리얼 이해를 위해 적을 여러 번 때리는 노가다는 요구하지 않는다.

새 대사 예시:

> 군관: “앞의 길은 열렸습니다. 하지만 적의 궁수가 진영을 지키고 있습니다.”
>
> 조조: “길만 보고 달려들지 마라. 우리가 설 곳부터 정한다.”
>
> 유비: “백성이 머무는 마을입니다. 불길이 번지기 전에 싸움을 끝냅시다.”

제작 요소: 평지·길·숲·얕은 물·다리·마을·진영 7지형, 일반병 1종, 장수 기본 스프라이트, 근접 공격·피격·퇴각·화재, 조조·유비·관우·장비·장보·장량 초상.

### S02 — 사수관 구원

**목적:** 여러 장수의 역할, 호위·회복, 출진 배치를 익힌다.

- 지도: 22×14칸. 북쪽 관문, 중앙 평지, 서쪽 숲의 우회로.
- 플레이어: 조조·하후돈·하후연·조인·조홍·악진 6명; 처음으로 출진 준비 화면을 사용한다.
- 우군: 손견과 2개 일반 부대, 후속 우군 관우.
- 적: 화웅과 보병·궁병 등 10부대.
- 승리: 화웅 퇴각. 패배: 조조 퇴각 또는 16라운드 종료 시 미달.
- 손견은 손상된 상태로 시작한다. 손견 퇴각은 전투 패배가 아닌 보조 목표 실패다.

| 시점 | 이벤트·규칙 |
|---|---|
| 준비 | 손견 생존 보상이 있다는 사실을 공개; 회복품 수량 확인 |
| 첫 적 차례 | 손견 방향 적 2개가 접근; 구조에 필요한 시간을 보장 |
| 아군 3라운드 | 서쪽 우군 관우 도착; 접근 경로 표시 |
| 관우·화웅 인접 | 일기토 발생; 퇴각 상태와 목표를 동시에 갱신 |
| 승리 | 손견 생존 여부에 따라 별도 보상·대화 |

전술 해법: 기병이 가까운 적을 분산하고 보병이 손견 주변을 막는다. 조조가 회복품으로 손견을 지원한다. 하후연은 궁병을 견제한다. NPC의 보스 처치로 기본 보상이 사라지지 않는다.

새 대사:

> 하후돈: “관문만 뚫으면 된다. 내가 선두에 서지.”
>
> 조조: “앞에 고립된 군대가 있다. 저들을 잃고 얻는 승리는 오래가지 못한다.”

### S03 — 호로관의 맹장

**목적:** 강적을 무작정 공격하지 않고, 집중·회복·위치로 상대한다.

- 지도: 24×14칸. 동쪽 성문, 중앙 평지, 서쪽 아군 진입 지점.
- 아군: S02의 6명. 우군 유비 3형제.
- 적: 여포와 11개 일반 부대. 여포는 높지만 가시적인 능력치와 공격 범위를 가진다.
- 승리: 여포 퇴각. 패배: 조조 퇴각 또는 18라운드 종료 시 미달.
- 초반 여포는 성문 방어, 아군 3라운드에 진격한다. 해당 변화는 사전 대화와 진격 표시로 예고한다.
- 무조건 즉사시키는 숨은 판정이나 무한 증원은 사용하지 않는다.
- 우군과 여포의 접근 이벤트는 짧은 연출과 소량 피해로 전황을 바꾼다. 전투 전체를 대신 끝내지 않는다.
- 보조 목표: 우군 2명 이상 생존. 보상: 방어 장비와 관계 기록.

전술 해법: 일반 궁병부터 정리하고 보병은 여포의 돌파 길을 제한한다. 하후연이 거리를 유지하며 공격하고, 조조는 회복과 아군 강화를 분담한다. 여포의 위협 범위를 상시 켜면 위험을 읽을 수 있다.

새 대사:

> 악진: “한 사람이 저렇게 전열을 밀어붙일 수 있습니까?”
>
> 조조: “한 사람이 강하면, 우리는 함께 싸우면 된다.”

### S04 — 낙양 추격·퇴각

**목적:** 목표가 전멸이 아닐 수 있다는 점, 후위와 탈출 판단을 익힌다.

- 지도: 26×16칸. 갈림길, 숲의 복병 지역, 남서 탈출구.
- 아군: 6명. 적: 초기 6부대, 복병 6부대, 추격대 최대 3부대. 증원 수는 유한하다.
- 준비 선택: “깊이 추격한다” 또는 “퇴로부터 확보한다”. 두 선택 모두 같은 전투에 진입하되 배치·추가 보상이 달라진다.
- 초기 목표: 정보 지점 `(18,5)` 확인. 확인 후 목표: 조조가 탈출구 `(2,13)`에 도달.
- 아군 3라운드 또는 경고된 숲 경계 진입 중 먼저 발생한 시점에 복병 공개, 한 번만 발생한다.
- 추격 선택: 정보 지점은 멀지만 보조 보물 획득 가능. 퇴로 선택: 탈출구 근처 후위 2명 배치.
- 라운드 제한 18. 조조가 탈출하기 전에 다른 장수도 탈출할 수 있다.
- 조조 탈출 시 전투는 즉시 종료하고 남은 동료는 일반 퇴각 처리한다. 남겨진 동료를 영구 사망시키지 않는다.
- 보조 목표: 모든 아군 탈출. 숨겨진 보물보다 기본 목표를 먼저 달성해도 손해를 크게 주지 않는다.

새 대사:

> 조인: “숲이 조용합니다. 적이 달아난 것 같지는 않습니다.”
>
> 조조: “추격보다 중요한 것이 있다. 돌아갈 길을 잃지 마라.”

### S05 — 청주의 항복

**목적:** 공격 책략·회복·숲의 전술, 항복 이벤트를 익힌다.

- 지도: 24×16칸. 두 마을, 중앙 숲, 북동쪽 황건 진영.
- 보유 장수: 기존 6명과 순욱·순유·전위, 총 9명. 출진 상한 8명.
- 필수 출진: 조조·순욱·순유. 다른 장수 5명을 선택한다.
- 적: 일반병·궁병 12부대와 우두머리 1명.
- 승리: 진영 2개 점령 후 우두머리 퇴각 또는 항복. 패배: 조조 퇴각 또는 18라운드 종료 시 미달.
- 점령: 진영 칸에 아군이 정지해 행동을 마치면 점령한다. 적이 들어오면 다시 빼앗길 수 있다.
- 초기 날씨: 맑음. 책략 조건과 회복을 먼저 익히고 날씨 변화는 후속 전투로 넘긴다.
- 아군 2라운드: 선택 가능한 순욱의 화계 안내. 사용하지 않고 다른 방식으로 이길 수 있다.
- 진영 2개 점령·우두머리 HP 50% 이하: 항복 제안 1회. 수락하면 승리, 거부하면 전투 지속.
- 항복 수락·격퇴 모두 기본 보상 동일. 이후 포로 처우 대화와 민심 기록만 달라진다.

새 대사:

> 순욱: “모두가 같은 이유로 황건의 깃발을 들지는 않았을 것입니다.”
>
> 전위: “칼을 놓으면 보내주는 겁니까?”
>
> 조조: “칼을 놓는 것과 군율을 지키는 것, 둘 다 확인한다.”

5전투 종료 후 플레이어는 기병·보병·궁기병·책사·지원·무도가의 역할, 호위·강적·탈출·점령 목표를 경험한다. 이 구간의 재미를 검증하기 전에는 전체 42전투를 일괄 제작하지 않는다.

## 7. 이벤트·시나리오 데이터 명세

각 전투는 코드 속 조건문보다 데이터로 표현한다.

```text
scenario: id, title, chapter, mapId, prerequisites, turnLimit
deployment: requiredUnits, optionalUnits, capacity, zones
objectives: primary, defeat, optional, reward
event: id, trigger, condition, priority, once, actions
trigger: phaseStart / unitMoved / hpChanged / unitRetreated / zoneCaptured
actions: dialogue / camera / spawn / status / objective / flag / reward
```

- 이벤트는 고유 ID와 `once` 기록으로 중복 실행을 막는다.
- 같은 판정에서 전투가 끝나면 결과를 한 번만 정산한다. 보스 퇴각·일기토·전체 전멸이 함께 발생해도 보상 중복은 없다.
- 패배 조건을 먼저 판정한다. 조조와 마지막 적이 같은 판정에서 퇴각하면 패배로 처리한다.
- 카메라와 대화 중에는 추가 전투 입력을 받지 않는다. 앱 중단 시 이벤트의 확정 상태를 저장한다.
- 원작과 비교할 항목은 별도 표로 관리한다. 미확인 원작 수치를 새 시나리오에 섞지 않는다.

## 8. 저장·복귀

저장 내용: 버전, 캠페인 위치, 선택·생존 플래그, 장수·장비·아이템, 지도 변경, 부대 위치·HP·MP·행동 여부, 진영·라운드, 이벤트 실행 기록, 난수 상태.

웹에서는 IndexedDB를 기본으로 한다. 앱에서는 동일한 저장 인터페이스를 사용하고 OS의 중단·재개를 처리한다. 원자적 저장과 직전 정상 세이브 백업을 두며, 복구 실패 시 오류와 마지막 정상 지점을 안내한다. 내보내기·가져오기 기능으로 브라우저 데이터 삭제에 대비한다.

확정 행동 뒤 자동 저장, 전투 시작·종료의 별도 체크포인트, 3개 수동 캠페인 슬롯을 제안한다. 상세 설정은 언제든 바꿀 수 있고 대화 기록도 저장한다.

## 9. 웹→모바일 개발 구성

- TypeScript + Vite + Phaser: 전장·도트·카메라·효과.
- HTML/CSS UI 레이어: 대화·장수 목록·설정·장비. 터치 크기와 글자 크기를 화면별로 조정한다.
- 전술 코어는 UI와 분리: 이동·공격·책략·적 AI·시나리오 이벤트를 같은 데이터로 실행한다.
- 로컬 저장부터 구현한다. 필수 로그인이나 서버 없이 캠페인을 플레이할 수 있게 한다.
- 완성된 웹 번들을 Capacitor의 앱 컨테이너에 넣는다. Android SDK/JDK와 macOS/Xcode의 iOS 빌드 단계는 별도로 검증한다.
- 엔진·플러그인 버전은 구현 시작 때 고정한다. 이번 조사에서 특정 버전 조합의 빌드를 검증한 것은 아니다.

## 10. 개발 순서와 완료 기준

| 단계 | 결과 | 검증 기준 |
|---|---|---|
| D0 — 기획 검토 | 이 문서·화면 3종·아트 보드 | 화면 방향·원작 유사도·첫 전투 범위 확인 |
| D1 — 무아트 전술 검증 | 단색 지도·기본 부대의 영천 | 이동·공격·반격·NPC·승패·저장·복귀가 일관되게 작동 |
| D2 — 아트 적용 전투 1개 | 리마스터 영천·대화·출진·결과 | 모바일 화면에서 부대·목표·명령이 읽히고 1전투 완주 가능 |
| D3 — 초반 5전투 | 9명 보유 장수·8병과·5맵·성장·상점 | 각 목표·이벤트·보상·분기가 작동하고 이어서 하기 가능 |
| D4 — 모바일 패키징 | Android 앱, 이후 iOS 앱 | 설치·오프라인·중단/복귀·음향·회전·안전 영역 실기기 확인 |
| D5 — 전체 캠페인 확장 | 42개 제작·36개 한 회차 | 전투별 자동 검증·장수 생존·두 노선·엔딩 기록 |

전투의 필수 검증: 도달 불가능한 칸 차단, 상성·지형의 표시와 판정 일치, 공격 가능 범위, NPC/적 차례 종료, 증원 중복 방지, 보상 1회 정산, 중간 저장 재개, 선택 이벤트 중 재개, 좁은 화면의 버튼 충돌.

기간은 인원·아트 제작 방식·원작 일치 수준을 정한 뒤 산정한다. 현재는 제작 단위와 검증 기준을 확정하는 단계다.
