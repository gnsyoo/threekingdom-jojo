# 사마의전 제작 기획

사마의의 시점으로 상용·오장원·요동을 지휘하는 모바일 중심 전술 RPG다. 원작 계열의 격자 전술과 출진 준비 방식은 참고하되 이야기·대사·인물·그림은 이 프로젝트에서 구성한다.

- [현재 게임과 대사·화면](../prototype/SIMA_CAMPAIGN.md)
- [전술·시나리오 기획](GAME_DESIGN.md)
- [아트·UI 제작 명세](ART_UI_SPEC.md)
- [역사와 UI 자료 출처](REFERENCES.md)

현재 세 원정은 실제 게임에 구현돼 있다. 사마의전의 초상 8명·동작·전장 세 장을 새로 만들고, 오장원은 방어 목표로 구현했다. 모바일 세로 배치를 우선하며 PC·태블릿·가로 회전을 함께 검수한다.

`images/`의 초기 콘셉트는 조조편 제작 당시 승인된 메뉴 구조·미술 방향의 기록이다. 최신 사마의전의 인물·전장과 실제 UI는 `../prototype/images/sima-*.png` 및 위 제작 기록을 기준으로 한다.
