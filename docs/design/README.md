# 모바일 삼국지 전술 RPG — 1차 기획·그래픽 검토

작성일: 2026-10-03 · 상태: 구현 전 검토안

조조전에서 익숙한 **격자 전투, 병과·지형 전술, 장수와 장비의 성장, 이야기 선택과 생존 이벤트**를 중심으로 한 모바일 싱글 플레이 SRPG를 제안한다. 브라우저에서 먼저 개발하고 같은 게임을 Android·iOS 앱으로 패키징한다.

사용자가 선택한 아트 방향은 **도트 전장 + 정교한 인물 일러스트**다. 가로 플레이를 기본으로 설계했다. 아래 내용의 전투 수치·대사·신규 분기·제작 수량은 새 게임을 위한 제안이며, 원작의 확정된 데이터가 아니다.

이미지는 화면의 분위기·정보 우선순위·그래픽 조합을 평가하기 위한 콘셉트다. 실제로 조작되는 게임 화면이나 완성된 스프라이트 시트가 아니다. 정확한 버튼 크기·한글 조판·프레임 정렬은 명세를 기준으로 구현한다.

## 이번 초안의 결정

- 가로 화면, 평면 사각 격자, 3/4 시점 도트 캐릭터. 원작의 형태·배치를 살리면서 세부 묘사를 높인 **리마스터 도트 전장**을 사용한다. 등각 투영은 사용하지 않는다.
- 색이 차분한 전장, 읽기 쉬운 현대적 패널, 금속·붓·천 질감을 절제해서 사용한다.
- 조조 중심의 삼국지 캠페인. 역사적 사건을 바탕으로 새 대사와 이벤트를 작성한다.
- 첫 플레이 목표는 영천→사수관→호로관→추격/퇴각전→청주로 이어지는 5개 전투다.
- 첫 제작 검증용 전투는 영천 1개다. 조작과 아트가 검증되면 나머지 4개를 제작한다.
- 캠페인·로컬 저장부터 개발한다. 온라인 운영, 대전, 확률형 모집은 별도 단계의 후보다.
- 전술 규칙은 화면과 분리해서 웹과 앱이 같은 데이터·판정을 사용한다.

## 검토 순서

1. 전투 화면: 도트 밀도, 장수 크기, 지도 면적, 하단 명령이 마음에 드는가?
2. 인물 일러스트: 조조·하후돈·순욱의 얼굴, 복식, 표정 방향이 맞는가?
3. 출진 준비: 장수 목록과 장비를 작은 화면에서도 편하게 읽을 수 있는가?
4. 시나리오: 원작과의 유사도를 더 높일 것인가, 신규 가상 전개를 더 넓힐 것인가?
5. 제작 범위: 1개 전투로 먼저 검증한 뒤 5개 전투까지 진행하는 순서가 적절한가?

이번 결과물은 기획 문서와 이미지 초안이다. 플레이 가능한 웹 게임, 모바일 빌드, 최종 게임 리소스는 아직 제작·검증하지 않았다.
