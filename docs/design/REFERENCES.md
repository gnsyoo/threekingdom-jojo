## 직접 본 원작 그래픽

- [공식 화면 1 — 지도와 초상 대화](https://www.gamecity.ne.jp/products/products/ee/images/gamen/sousou_1.jpg)
- [공식 화면 2 — 실내 도트 장면과 대사창](https://www.gamecity.ne.jp/products/products/ee/images/gamen/sousou_2.jpg)
- [공식 화면 3 — 격자 전장의 책략 연출](https://www.gamecity.ne.jp/products/products/ee/images/gamen/sousou_3.jpg)

공식 이미지는 160×120의 저해상도 자료다. 화면 구조·도트 지도·초상 조합·효과의 대비는 관찰할 수 있으나 원본 타일의 정확한 픽셀 크기나 애니메이션 프레임 수를 확정할 수 없다.

관찰 결과:

1. **전장과 이벤트가 같은 세계처럼 보인다.** 지도·실내·캐릭터가 도트 언어를 공유한다. 새 게임도 이야기 배경에 도트 디오라마를 사용한다.
2. **초상이 인물을 설명한다.** 전장의 작은 캐릭터는 위치와 병과를, 초상은 성격·감정을 담당한다. 사용자 선택에 따라 새 초상은 정교한 일러스트로 제작한다.
3. **책략은 짧고 크게 강조한다.** 넓은 효과와 색 대비로 전투의 중요한 순간을 보여준다. 모바일에서는 피격 위치·범위를 먼저 읽을 수 있도록 효과의 불투명도와 길이를 제한한다.
4. **원작의 상단 아이콘과 작은 글씨는 데스크톱 중심이다.** 모바일에는 주요 명령을 하단에 모으고, 숫자와 상태를 확대하며, 상세 정보는 펼쳐 보게 한다.

원작 이미지는 비교 자료로만 사용한다. 새 게임에 들어가는 초상·도트·UI·효과·대사는 새로 제작한다. 사용자의 별도 권리 보유 여부는 이번 초안에서 가정하지 않았다.

## 접근 제한과 확인하지 못한 항목

- StrategyWiki 페이지: HTTP 403. 분석 근거에 포함하지 않았다.
- 검색에 나타난 일부 Tistory 전체 공략: HTTP 404. 검색 요약만으로 보상·수치를 확정하지 않았다.
- Tistory 본문에 연결된 Daum CDN 이미지: HTTP 403. 공식 제품 페이지의 이미지로 화면 구조를 확인했다.
- 공식 매뉴얼 원본, 원본 데이터 테이블, 전체 전투의 실제 플레이, 모바일 실기기 성능: 미확인.
- Phaser·Capacitor 버전은 실제 개발 시작 때 함께 고정한다. 최신 소개 문서가 특정 조합의 앱 빌드 성공을 보장하지는 않는다.

## 원작 요소를 새 게임에 적용하는 방식

| 원작에서 확인한 요소 | 새 게임의 설계 | 구분 |
|---|---|---|
| 사각 격자·턴제 부대 전투 | 사각 격자, 아군→우군→적군 라운드 | 판정·세부 수치는 새 설계 |
| 병과 역할·지형의 영향 | 초기 6역할, 지형 비용과 방어 보정 표시 | 역할은 참고, 계수는 새 설계 |
| 무구 사용에 따른 성장 | 무기·방어구 숙련도, 장비 비교 | 성장량·상한은 새 설계 |
| 이야기 선택과 후반 분기 | 공통 30전투 뒤 통일/연합 6전투씩 | 새 분기와 새 대사 |
| 특정 장수 생존 이벤트 | 전위·곽가·하후연의 조건부 생존 이벤트 | 역사 소재를 참고해 새 이벤트 작성 |
| 특수 무구와 보물 도감 | 전술적 효과를 가진 장비와 획득 기록 | 아이템 데이터는 새 제작 |
| 작은 초상·도트 이벤트 | 정교한 인물 일러스트 + 도트 디오라마 | 사용자 선택 반영 |
| 데스크톱 명령 UI | 터치 미리보기·확정·되돌리기·중간 저장 | 모바일에 맞춘 새 설계 |

## 남은 조사 우선순위

화면·시나리오 방향을 검토한 뒤 원작과의 일치 정도를 확정한다. 그때 필요한 항목부터 추가 확인한다: 이동·반격 범위, 지형 표, 상태 이상 지속, 승급 시점, 적 레벨 산정, 원작 전투의 배치·이벤트 순서. 이번 제작안은 이 값들을 이미 역공학했다고 가정하지 않고 독립적인 규칙으로 시작한다.
